5. Did you add a bonus feature to your submission? If so, what is it and how should we see it?
I added two bonus features. The first is a recent searches feature, which makes it so that when you make a search, it is added to a recent searches list. You may then click any item in this list to immediately repeat the search without having to enter it again.
The second feature I added is a favorites feature. This feature lets you set artists, albums, or tracks as favorite so that you may click on them to be directed straight towards the item's page. 
Both features save their data locally, meaning that they are actually saved and remain after refreshing the website.
